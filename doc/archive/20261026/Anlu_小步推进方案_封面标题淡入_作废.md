# 小步推进方案：封面标题改用掩膜叠加 + 文字淡入

## 1. 背景与目标

当前封面标题是**画在 BMP 里**的：图片从 512×384 放大到 640×480 时标题一起被拉伸，边缘偏软；同时"淡入"这类片头效果做不了。

**目标**：

1. 封面标题改由 **FPGA 掩膜**绘制（屏分辨率 1:1，不参与缩放，更锐利）；
2. 标题上电后**淡入**（约 1 秒，alpha 0→255）；
3. 封面 BMP 换成**无文字**的纯照片，避免与掩膜文字重复；
4. **不影响三页菜单的文字**（同一条叠加通路，必须回归）。

## 2. 现状事实（代码已核）

`mask_overlay.v`：

- 两个窗口：左 `x 60..259`、右 `x 360..559`，`y 340..419`（各 200×80）；
- 块内位序：`sel = ly*200 + lx`（14 位），字地址 `sel[13:5]`、位索引 `sel[4:0]`；
- 块编号 `midx = {page[1:0], ~in_l}` → **8 块，每块 512 字**（16000 位，补零到 16384）；
- 第 1 页（`page==0`）两块当前为**全零**；
- 文字颜色固定 `#3A2A1E`，1bit 硬边，无 alpha。

`txt_all.mif`：4096×32bit，由 `sim/remap_mask_rom_cover.py` 从旧 MIF 搬块生成。

## 3. 改动步骤

### 3.1 生成第 1 页掩膜（素材侧）

新脚本 `sim/make_cover_mask.py`：用 PIL + 微软雅黑，直接把文字渲染成 **200×80 / 1bit**，按 `ly*200+lx` 打包成 500 字（补零到 512），写入 `txt_all.mif` 的块 0 与块 1：

| 块 | 内容 |
|---|---|
| 块 0（左窗口） | 「木与豆咖啡」大号（约 34px）+ 下方 `WOOD & BEAN`（约 12px） |
| 块 1（右窗口） | 「每日现磨 · 手冲与意式」（约 18px，垂直居中） |
| 块 2~7 | 保持原菜单页两块不变（从现 MIF 搬运） |

### 3.2 文字淡入（`mask_overlay.v`）

1. 新增输入 `fade_alpha[7:0]`（由顶层给）；
2. 命中掩膜像素时不再直接输出 `TEXT_COLOR`，改为
   `rgb_out <= rgb_in + ((TEXT_COLOR − rgb_in) * alpha) >> 8`（逐通道）；
3. `alpha == 255` 时退化为原行为（完全覆盖），保证菜单页不变；
4. 顶层：`page==0` 时 alpha 由计数斜坡上升（约 1 秒），其它页固定 255。

**注意**：乘法只在命中掩膜的像素上生效，但为了时序简单，按"每像素都算、最后按命中选"实现（3 个 8×8 乘法，视频域 +12ns 余量足够）。

### 3.3 封面图去文字

用 `sim/compose_cover_v2.py` 的裁切逻辑，但不叠加文字，输出 **512×384 / 24bit** 的 `PIC1.BMP`（旧版保留为 `PIC1_带文字版.BMP`）。

## 4. 验收方式

**构建门禁**：黑盒 0、无 `PHY-9013`、无路由错误、bit 新鲜、`video ≥ 0`、`ext_mem ≥ −0.8`。

**仿真**：用 `tb_mask_overlay`（若不存在则新建小 tb）确认 ① 菜单页（page≥1）输出与原行为逐像素一致；② page0 在 alpha=255 时等于 TEXT_COLOR；③ alpha=0 时等于背景。

**上板**：

1. 封面页：照片无内嵌文字，**标题由 FPGA 绘制**、上电后约 1 秒淡入；
2. 三页菜单：文字位置、内容、滑入动画**与之前完全一致**（重点回归）；
3. 封面页仍不可放大；SW2 音量预设正常。
