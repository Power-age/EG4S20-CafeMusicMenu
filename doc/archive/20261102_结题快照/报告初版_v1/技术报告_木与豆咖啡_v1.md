# 木与豆咖啡 · 店内音乐电子菜单

——基于安路 EG4S20 的单 FPGA 店内音乐电子菜单

## 摘要

本作品是一台置于咖啡店柜台的电子菜单板，面向数字广告牌与商业展陈终端场景，是 2026 全国大学生嵌入式芯片与系统设计竞赛 FPGA 创新设计赛道（安路赛道）选题一的完整实现。整机只有一颗安路 EG4S20 FPGA，无处理器、无操作系统：从 TF 卡读取、图像缩放、图层叠加到 HDMI 输出全部由硬件逻辑完成，上电即自动轮播四页商品海报并播放背景音乐，底部频谱随音乐起伏。

上电后 FPGA 扫描 FAT32 格式 TF 卡，将四张不同画幅的商品海报（1280×960 4:3、1280×960 4:3、1280×720 16:9、1024×1024 1:1）解码后按比例适配到 640×480 输出，居中并自动补黑边，常驻板载 2M×32bit SDRAM 的四个分区；翻页只改分区号，在帧消隐边界切换，零加载、无撕裂。48kHz 音乐以裸 PCM 流式读出，经 HDMI 与画面同步播放；曲目切换、快进快退、音量、亮度、对比度均可用板载按键与拨码完成，并在 OSD 上回显。

在满足赛题基础要求之外，作品实现了中文叠加、转场、局部放大、实时参数调节与音频可视化五项扩展：商品名与卖点以 1bit 掩膜由 FPGA 逐像素叠加，左上角中文角标随翻页滑入并在设置面板打开时依然显示；支持揭幕与黑场两种转场；支持 2 倍双线性局部放大且放大窗口按页对准商品；对 PCM 实时做 1024 点定点 DFT，按对数分为 40 段频谱贴底部渲染。

最终版本资源占用为 slices 87.74%、BRAM9K 15/64、DSP 11/29；布局布线后九个时钟域建立与保持时间全部无违例（显示主通路建立裕量 +11.73ns）。比特流已固化至 QSPI Flash，断电重启后自动运行、无需 PC，换卡即换菜单。

## 第一部分  作品概述

### 功能与特性

- （1）多画幅自适应播放：识别 FAT32 根目录 PIC1~PIC4.BMP，四页分别为 4:3、4:3、16:9、1:1，按比例适配 640×480 并自动补黑边，手动翻页或自动轮播；

- （2）背景音乐：48kHz 裸 PCM 经 HDMI 与画面同步播放，支持 16 档音量、曲目切换与 ±10 秒快进快退；

- （3）中文叠加：左上角中文角标（每页不同文案）与商品卖点以 1bit 掩膜由 FPGA 叠加，翻页时滑入，设置面板打开时仍正常显示；

- （4）转场与放大：揭幕、黑场两种转场；2 倍双线性放大，放大窗口按页对准商品，封面不放大；

- （5）实时调节与可视化：亮度、对比度、音量实时可调并在 OSD 回显；40 段频谱贴屏幕最底行随音乐起伏；

- （6）可靠性：四分区常驻、切图零加载；比特流固化 Flash，上电自启、长期无人值守运行。

### 应用领域

作品定位为门店菜单板、数字广告牌与商业展陈终端，典型场景是咖啡店、烘焙店、甜品店的柜台：设备上电即播，无需电脑、手机或联网；店员换菜单只需换 TF 卡内容，无需专业维护；四页图文循环展示，背景音乐与频谱营造氛围，亮度、对比度、音量可在现场即时调整。

其平台化硬件底座可推广到更多场景：餐厅与奶茶店的点餐价格屏、门店与展台广告欢迎屏、酒店楼宇信息发布屏、教室与会议室展示终端。图片（FAT32→BMP→帧缓存→HDMI）、音频（PCM→DFT→HDMI）、交互（按键/拨码/OSD）三条通路相互独立，可分别复用为电子相册、音频可视化装置与信息发布终端，也是 FPGA 课程中“图像+音频+存储+高速接口”的综合实验载体。

### 主要技术特点

- （1）纯硬件、无操作系统：全部功能由 FPGA 逻辑实现，无外部 CPU 与软件，状态确定、上电即播；

- （2）四分区常驻零加载：四张图上电后常驻 SDRAM 四个分区，翻页只改分区号，在帧消隐边界原子生效，无加载等待、无撕裂；

- （3）真实 DFT 频谱：对增益后 PCM 实时做 1024 点 Q15 定点 DFT、对数分 40 段，配合跨频平滑、峰值保持与固定参考映射，柱形稳定不抖；

- （4）位图掩膜叠加：4 页中文角标掩膜合成 4096×32bit 只读 ROM 固化进 BRAM，文字与底图分层、逐像素叠加，随翻页滑入；

- （5）多画幅自适应：按页读取各图的原始宽高，等比缩放并计算居中偏移，四页画幅不同也能满幅显示且不拉伸；

- （6）规范多时钟域：50/75/125/25/12.288MHz 多域之间，多 bit 数据走异步 FIFO、单 bit 控制两级同步，SDC 约束完整，最终九个时钟域建立与保持时间零违例。

## 第二部分  系统组成及功能说明

### 整体介绍

系统以安路 EG4S20 FPGA 为核心，由“板载外设 + 片内逻辑”构成，总体框图见图 2。板载外设包括：TF（MicroSD）卡座、一片 2M×32bit SDRAM、QSPI Flash、HDMI 接口、4 个按键、4 位拨码开关与 8 位数码管；外部只需一根 HDMI 线接显示器、插入存有素材的 TF 卡。片内逻辑按数据流向分为图片、显示、音频、控制四条通路。

- （1）图片通路：TF 卡 → SD/SPI 控制器 → FAT32 根目录扫描 → 簇链跟随（相对扇区→物理 LBA）→ BMP 解码与等比缩放 → 异步 FIFO → 帧缓存写控制器 → 板载 SDRAM 四分区。

- （2）显示通路：视频时序 640×480@60 → 帧读出（帧边界切换）→ 亮度/对比度 → 转场（WIPE/FADE）→ 2 倍商品放大 → 中文角标（1bit 掩膜）→ OSD/频谱柱 → AXIS → HDMI 1.4b 发送。

- （3）音频通路：TF 卡裸 PCM 流式播放（BRAM 缓冲）→ 音量增益/TONE 源选择 → I2S 与 ACR → HDMI 音频；增益后 PCM 同时送 1024 点 DFT，结果作为 40 段频谱叠加到显示通路。

- （4）控制通路：按键/拨码经消抖与长短按判别后，控制翻页、音量、曲目、快进快退、转场与设置面板；数码管动态扫描显示图号、音量与装载状态。

### 2.2.3  电路各模块介绍

电路按功能分为时钟、TF 卡、板载 SDRAM、HDMI、人机交互五个模块，关键引脚约束见表 3。

- （1）时钟：50MHz 晶振经 sys_pll 产生 75MHz（SD 读取）与 125MHz（SDRAM、HDMI 5× 串行）；video_pll 产生 25MHz 像素时钟；audio PLL 产生 12.288MHz 音频 MCLK。

- （2）TF 卡接口：工作在 SPI 模式，控制器通过 sd_dclk、sd_mosi、sd_miso、sd_ncs 四线与卡通信，完成扇区读写。

- （1）TF 卡与 FAT32：sd_card_top（spi_master、sd_card_cmd、sd_card_sec_read_write）完成 SPI 物理层与扇区读写；fat32_volume_scanner 扫描根目录并按文件名定位 PIC1~4.BMP 与 TRACK01~03.RAW；fat32_chain_reader 跟随 FAT 簇链，把相对扇区翻译为物理 LBA，支持文件碎片化与根目录跨簇；sec_channel_arbiter 对同一扇区通道按优先级仲裁。

- （2）BMP 解码与等比缩放（bmp_read）：解析 24bit BMP 头与像素，按目标区域比例计算缩放系数，以定点乘法实现等比缩放与居中偏移，四页画幅不同也能满幅显示、不拉伸；按素材规格要求（宽高均不小于 640×480），小图放大通路已从设计中移除。

- （3）四分区帧缓存（resident_switch、frame_read_write、sdr_as_ram）：上电把四张图顺序写入SDRAM 四个固定分区；显示侧只在帧消隐期切换分区号，零加载、无撕裂；读、写各经一块异步 FIFO 跨 125/25MHz 时钟域。

- （4）音频流式播放（wav_stream_player、track_controller、track_list）：以 BRAM 缓冲从 TF 卡流式读出裸 PCM，扫描曲目并允许编号缺洞，播完自动下一首；记录簇索引实现 ±10 秒快进快退，seek 后清 FIFO 重灌并同步倒计时；audio_volume_gain 用 Q15 增益实现 16 档（等 2dB）音量，tone_dds 在无曲目时直出测试音；HDMI 音频侧按 I2S 64fs 组帧，ACR 以 N=6144、CTS 动态测量保证音画同步。

- （5）音频频谱（spectrum_engine、spectrum_render）：对增益后 PCM 取 1024 点分块，用 Q15 正余弦表做定点 DFT，按 |I|+|Q| 求幅度、对数分 40 段，再经跨频 3 点平滑、帧间低通与峰值保持，按固定参考映射为柱高；渲染为屏幕最底行（y=479）的 40 段柱形，每 42 帧刷新。处理流程见图 10。

- （7）转场与放大（video_effect_overlay、video_zoom）：揭幕（WIPE）与黑场淡入淡出（FADE）均在帧边界提交；2 倍双线性放大对相邻 4 像素加权，放大窗口按页配置（封面不放大），两个按键功能一致，放大过程中翻页自动退出放大。

- （8）OSD 与信息条（osd_buffer、osd_renderer、status_bar_render、track_countdown）：中央设置面板列出音量、亮度、对比度、转场、自动轮播、周期、测试音七项，短按打开、双击关闭、无操作自动关闭；右上显示“歌名 -MM:SS”倒计时，无曲目显示 --:--。

- （9）人机交互与跨时钟域（key_longshort、seg_scan、menu_controller）：按键消抖并区分短按、长按与双击；数码管动态扫描显示图号、音量与装载状态。多 bit 数据一律走异步 FIFO（双时钟 BRAM + 格雷码指针），单 bit 控制走两级寄存器同步，SDC 对异步时钟对设置 set_clock_groups -asynchronous。

## 第四部分  总结

### 可扩展之处

作品仍可从以下方向完善：一是内容容量，当前常驻四页，可在 SDRAM 容量允许下扩展更多分区，或引入外置字库使换文案无需重烧；二是音频可视化，可细化频段、加入节拍检测与随节奏变化的配色；三是交互与联网，可加入旋钮、触摸或红外遥控，并预留串口/网络实现远程下发菜单；四是编码支持，可由 BMP 扩展到 JPEG/PNG 解码与多语言；五是鲁棒性，可补充看门狗自恢复与素材校验。当前图片、音频、交互三条通路相互独立，上述扩展可在不改动整体框架的前提下逐模块叠加。

### 心得体会

本作品从官方样例“能显示一张图”起步，逐步做出一台上电即用的产品化电子菜单，过程中对“纯硬件系统如何组织复杂功能”体会很深。

第一，小步推进、每步可回退。我们把工作拆成几十个小任务，每完成一项就保留一个可上板的稳定点；构建脚本还加了门禁——建立与保持时间不全部达标，就不允许更新交付件。这让问题总能在很小的范围内被定位。

第二，仿真先行。OSD、掩膜、转场都先在仿真中用画帧与黄金值比对边界条件；做放大倍率改造时，正是靠“喂入坐标编码图案、逐像素比对映射”的测试台，才定位到“整行像素必须全部弹出、只取窗口部分”这一关键细节。

第三，时序不只是约束问题，也是资源与架构问题。多画幅、掩膜、频谱叠加逐步加入后，一度出现 4~20 皮秒的保持时间残差；换布局种子、增加修复轮次都无效，最后按素材规格移除用不到的小图放大通路，占用从 91.8% 降到 88.1%，九个时钟域才真正全部转正。

第四，资源约束会反向塑造设计。BRAM 用满后，频谱幅度改用 |I|+|Q| 的 L1 范数、缩放与混合尽量用移位加法，全片 DSP 只用了 11 个。

第五，产品化细节决定观感：素材要留文字安全区，避免被角标与频谱遮挡；切页要在帧边界提交避免撕裂；角标在设置面板打开时也要可见；换卡、断电重启都要能自动恢复。这些都不在赛题要求里，却决定一台设备能否长期放在柜台上。

最后，纯硬件系统的可靠性来自确定性：没有操作系统，就没有启动等待与崩溃；帧边界切换保证不撕裂；固化后断电再来电即可自动恢复。这让我们理解 FPGA 在低延迟、高可靠场合的价值。
