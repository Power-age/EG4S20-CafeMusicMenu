## 3. 频谱可视化链路（当前实现）

### 3.1 数据流

```
vol_audio_r (音量增益后的音频, 24bit signed)
   ↓ sample_valid
spectrum_engine  ── 1024 点采集 → 40 频段 DFT → AGC → 峰值保持
   ↓ bands[239:0]（40 × 6bit）
spectrum_render  ── 40 根条，12px 条 + 4px 缝，基线 y=471
   ↓
vout_data_wave → video_effect_overlay → osd_buffer_overlay → HDMI
```

### 3.2 `spectrum_engine.v`（`src/user_source/hdl_source/`）

**算法**：分块 DFT（不是 Goertzel——48kHz 下低频 `2cos(ω)` 全是 1.9999x，Q12 定点量化成 2.0 会变成无衰减振荡器，必然溢出）。

```
X_k = Σ x[n]·cos(2πkn/N) ,  Σ x[n]·sin(2πkn/N)
cos/sin 来自 1024 点查表（spec_cos.mif / spec_sin.mif，Q15）
```

**参数**

| 项 | 值 |
|---|---|
| 块长 N | 1024（分辨率 46.875 Hz）|
| 频段数 | 40 |
| 频段 k 值 | 前 20 个线性（k=1..20），后 20 个对数（k=21..256）|
| 频率范围 | 47 Hz ~ 12000 Hz |
| 幅度 | `|I| + |Q|`（L1 范数）|
| 更新率 | 约 24 Hz（采集 21ms + 计算 3ms）|

**当前映射（AGC）**

```verilog
agc_d = msb(当前幅度) - ref_msb[bin]      // ref_msb 是每频段长期峰值
agc_h = 26 + agc_d * 4                    // 钳位 0..63
噪声门: < 3 → 0
峰值保持: 每次更新降 1
```

`ref_msb[bin]` 更新规则：当前 > 基准 → 基准跟上；否则每块降 1。

## 4. 当前未解决问题 + 建议方案（重点）

### 4.1 问题：柱状图区分度不足

**现象**：40 根条高度接近，缺少参考图那种"错落有致、高低起伏"的视觉层次。左侧低频段幅度明显弱于右侧。

**已尝试且失败的方向**

| 尝试 | 结果 |
|---|---|
| 对数列度（msb × 2）| 太压缩，音量 1 和 15 差别很小 |
| 线性映射（`mag >> 18`）| 比例正确，但原始频谱本身就低频弱 |
| 频谱倾斜（压低频）| **方向反了**，高频霸屏，更糟 |
| 平方扩张（`h²/64`）| 有效果，但单独用不够 |
| 慢回落（每 4 次降 1）| 视觉"卡住"，已回退 |
| 逐频段 AGC（当前）| 各段站同一起跑线，但仍不够错落 |

### 4.2 建议方案 A：邻近频段平滑（非常推荐）

**解决的问题**：单频点 DFT 输出抖动大、相邻条不相关，看起来"毛刺"。参考图里相邻条是平滑过渡的"山丘"。

**实现**：3 点加权平均

```
h'[b] = (h[b-1] + 2·h[b] + h[b+1]) / 4
```

- 需要在引擎里缓存 3 个频段的高度（或渲染时读邻接）
- 代价：约 40 个加法器 + 2 级流水，面积很小
- 效果：视觉平滑度提升明显，且不会削平峰谷（权重 2:1:1）

**注意**：这一步应该在 AGC **之后**、峰值保持**之前**做。

### 4.3 建议方案 B：指数提升（gamma / expander）

**解决的问题**：AGC 之后各条仍在中间高度扎堆，峰谷差不够。

**实现**：`h' = (h / 63)^γ · 63`，γ 取 1.5~2

低成本近似（无除法）：

```
h' = h + (h·(h-32)) >> 6      // γ≈1.5 的二次近似
```

或直接查表（64 项小 ROM）。

- 代价：1 个乘法器或 64×6 bit ROM
- 效果：高峰更突出、低值更接近 0，层次感强

### 4.4 建议组合顺序

```
DFT 幅度
  → AGC 归一化（已有）
  → 邻近平滑 A（3 点加权）
  → 指数提升 B（γ=1.5）
  → 噪声门（已有）
  → 峰值保持（已有）
```

### 4.5 备选：换频段划分

如果做完 A+B 仍不理想，可考虑：

- 频段数从 40 → 32（条更宽，视觉更"稳"）
- 或低频段用更长的窗口（2048 点）提高低频分辨率

## 附录 A：频谱表生成脚本

```python
import math, os
OUT = r"D:\AAA_University\Anlu\Project\src\user_source\hdl_source"
N, FS, NB = 1024, 48000.0, 40

# 频段 k 值：前 20 线性，后 20 对数
ks = []
for b in range(NB):
    k = (b + 1) if b < 20 else int(round(20 * (256/20.0) ** ((b-19)/20.0)))
    k = max(1, min(256, k))
    if ks and k <= ks[-1]:
        k = ks[-1] + 1
    ks.append(min(256, k))

COS, SIN = [], []
for n in range(N):
    a = 2*math.pi*n/N
    COS.append(int(round(math.cos(a)*32767)) & 0xFFFF)
    SIN.append(int(round(math.sin(a)*32767)) & 0xFFFF)

def wm(path, data):
    L = ["WIDTH=16;", "DEPTH=%d;"%len(data), "ADDRESS_RADIX=UNS;", "DATA_RADIX=HEX;", "CONTENT BEGIN"]
    for i,v in enumerate(data): L.append("  %d : %04X;"%(i,v))
    L.append("END;")
    open(path,"w",encoding="ascii").write("\n".join(L)+"\n")

wm(os.path.join(OUT,"spec_cos.mif"), COS)
wm(os.path.join(OUT,"spec_sin.mif"), SIN)
```
