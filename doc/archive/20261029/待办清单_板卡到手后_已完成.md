## C. 上板验证（约 15 分钟）

**准备**：HDMI 接显示器（1024×600，建议"铺满"）、接音箱或耳机、插卡、接 USB 下载器。

- [ ] ① 上电：能出画面、可翻页（先确认板上原固件工作正常）
- [ ] ② 由助手 JTAG 烧入新固件（约 7 秒），确认烧录成功
- [ ] ③ 翻到**封面页**：480×360 放大铺满、**不变形**、无黑边；`PAGE 1/4`、歌名+倒计时、底部频谱都存在
- [ ] ④ 封面页**长按 KEY3 / KEY4**：**无反应**（放大已禁用）
- [ ] ⑤ 翻到**菜单页**：1280×960 缩小铺满，商品文字从两侧滑入
- [ ] ⑥ 菜单页**长按 KEY3 / KEY4**：2× 双线性放大正常
- [ ] ⑦ **封面 ↔ 菜单页来回切换 3 次**：画面正常、文字不串页（几何相同，重点看掩膜顺序）
- [ ] ⑧ **SW2 上拨**：音量立即归 0（静音、频谱归零）；**下拨**：音量立即到 15；随后按键调音量正常且不被开关覆盖
- [ ] ⑨ 断电重启（SW2 停在下档）：音量仍为 0，不会自动出声
- [ ] ⑩ 短按 KEY2/KEY4 翻页、KEY3 菜单开合、`TONE` 开关、长按切歌、±10s 快进快退：与之前一致

**判错线索**：文字出现在封面或错页 → 掩膜块顺序；封面页仍能放大 → 门控条件；画面错行/花屏 → 帧缓存写通路；整体花屏 → `ext_mem` 时序（看 `final_timing.rpt`）。

## F. 环境与已知坑（避免重复踩）

- **布局种子**：写在 `src/td_project/HDMI1.4b_Transmitter_v1.0_Runs/phy_1/settings.cfg` 的 `set phyWildParams {place seed 5}`。**每次进 TD GUI 跑过流程，这一行会被删**，重建前必须确认它还在，否则会静默退回默认种子（实测 `ext_mem` 会掉到 −5.8ns）。
- **三门禁**：黑盒 = 0、无 `PHY-9013`、`.bit` 必须晚于本次构建开始时间。`RUN-8102`/`PHY-8023`（布线失败）已在 `sim/loop.ps1` 里做成硬中止。
- **实时预览画面**：显示器若设"铺满"，会把 640×480 横向多拉 1.28 倍；素材已按 1/1.28 预压缩抵消。换 16:9 电视演示时比例会偏，建议设 4:3 或原始比例。
