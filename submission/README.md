## assets/ — 演示素材

| 文件 | 说明 |
|---|---|
| `PIC1.BMP` | 封面，1280×960，24bit 无压缩 |
| `PIC2.BMP` | 手冲页，1280×960 |
| `PIC3.BMP` | 卡布页，1280×720 |
